# CricketConnect Capacitor — Feature Parity Tracker

Architecture: this app is the **same legacy-app web code**, copied verbatim into `www/` and run inside Capacitor's native WebView. It is not a rewrite. Because of that, most features get parity automatically — they're literally the same JavaScript running — the exceptions below are the only places that genuinely need native-specific work.

Status legend (per Phase 2 Section 25 — "no fake completion"): **NOT STARTED** / **IN PROGRESS** / **IMPLEMENTED — NOT BUILT** (real code written and reasoned through against actual source, but never compiled — this sandbox has no npm registry access or Android SDK) / **BUILT — NOT DEVICE TESTED** / **DEVICE TESTED** / **PRODUCTION READY**. Nothing is marked past IMPLEMENTED — NOT BUILT until it has actually run — see README for exactly what has to happen on your machine first.

## Record Match plan (the actual point of this project)

Full architecture — how the current web recording actually works (verified from source), the camera architecture decision (options A-E), plugin selection with version caveats, permissions/video-settings/file-handling/upload plans, and known open questions — has moved to **`RECORD-MATCH-ARCHITECTURE.md`**, written this phase, so it isn't duplicated and drifting between two files. Short version: the score-overlay compositing (`overlays.js`'s `drawOverlay()` burned into the video via `canvas.captureStream()`) has no native equivalent, and is deliberately being built as its own later milestone (native camera pipeline first, without overlay — a known, visible regression until then — overlay restored after) rather than blocking on solving the hardest part first.

**TWA root cause investigation status: still not concluded**, unchanged from Phase 1 — the CAMERA/RECORD_AUDIO permission gap found and fixed didn't resolve the symptom, and the most promising unexplored lead (a second "XSpace" Chrome instance on the test phone) was never chased down. Worth knowing this migration proceeds regardless of that root cause, but it's possible the TWA had a smaller, fixable bug.
